# Nova Chat

可私有化部署的即时通讯。后端、运营后台、网页端、App（H5 / Android / iOS）使用同一套账号和同一套消息序号。数据在你的服务器上，名称和 Logo 可以更换。

群消息只存一份，用本群递增序号对齐每个成员的进度。长连接可以加机器，推送只打给当时在线的节点。断线后打开应用，按序号把缺口补上。

## 能力

- 私聊、群聊、系统通知。文字、图片、文件、语音、视频、名片、引用、转发、撤回、已读、@
- 好友审核与分组。群邀请、管理员、禁言、公告
- 朋友圈。站内钱包：转账、红包、充值与提现审核
- 一对一语音和视频。媒体走 WebRTC，跨网用 TURN
- 业务 JSON 整包加密。密码哈希入库
- 登录风控：失败锁定、新设备验证码、信任设备。管理端可开动态口令

## 部署

依赖 JDK 21、MySQL 8、Redis、RabbitMQ。上传文件需要 MinIO。步骤见 [Docker 部署](部署文档.md)。

## 定制开发

可以在现有消息链路和后台权限上继续改，不必从零再做一套 IM。包括换品牌、加业务功能、对接短信或已有账号、协助按部署文档上线。群通话和手机通知栏需要单独评估。说明使用场景、要改的端和预计上线时间。

## 范围

源码部署在你的机器上。服务器、域名、短信和对象存储另备。钱包的充值和提现由后台确认。群通话和手机厂商通知栏不在当前范围内。离线消息在再次打开后按序号补齐。
